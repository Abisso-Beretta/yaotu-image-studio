妖荼手机版 v0.2.1

- 修复添加参考图后请求失败的问题，改用原生 multipart 文件上传，保持图片字节完整。
- 修复生图 API 和辅助 API 只能保存一个配置的问题；支持独立保存、切换和删除多个配置，各配置的 API Key 独立存储。
- 兼容旧版已有的 API 配置和密钥，无需重新填写。
- 修复编辑未启用的辅助 API 配置时，测试连接和拉取模型使用错误密钥的问题。
- 修复保存下一张图片覆盖上一张的问题；每次保存生成独立名称，保留原始图片格式。

升级方式：在 App 的“设置 → 关于 → 检查更新”中下载新版 APK，直接覆盖安装。请勿卸载旧版，以保留本地配置与生成历史。
